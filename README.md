# EH Workouts (free PWA)
Static files only. No backend, API keys, or AI. Data stays in the phone's localStorage.

## Host free on GitHub Pages (one-time, needs a free GitHub login)
1. Sign in at github.com, then create a new **public** repo named `dylan-workout-app`.
2. Click "uploading an existing file" and drag in everything in this folder (keep the `data/` and `icons/` folders). Commit.
3. Go to Settings → Pages → Source: "Deploy from a branch", Branch: `main` / root → Save.
4. After about a minute the app is live at https://<username>.github.io/dylan-workout-app/
(Alternatives: Netlify Drop (app.netlify.com/drop, drag the folder in) or Cloudflare Pages. Both are free.)

## Install on iPhone
1. Open the URL in **Safari**.
2. Tap Share → **Add to Home Screen**.
3. Tap Add, then open it from the home-screen icon (full screen, works offline).
